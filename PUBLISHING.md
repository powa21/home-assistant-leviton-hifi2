# Publishing checklist

1. Confirm you have rights to distribute all included code under MIT.
2. Create an empty public repository at https://github.com/powa21/home-assistant-leviton-hifi2 (do not initialise with README or licence).
3. Extract this ZIP and upload its contents, including `.github` and `.gitignore`, using GitHub Desktop or git.
4. Check the Actions tab and resolve any HACS or hassfest failures.
5. Create release tag `v1.0.0` and mark it as a prerelease until live HACS installation and amplifier tests pass.
6. Test power, source, mute, low-volume adjustments, physical controller feedback and Apple Home pairing.
7. After successful testing, mark the release stable and consider default HACS catalogue submission.

Repository metadata and MIT licence are already included. No repository has been created by this package.
